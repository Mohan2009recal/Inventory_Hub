This project is the final submission for the Microsoft Full-Stack Integration capstone project.
Tech Stack

    Back-End: ASP.NET Core 8 Web API
    Front-End: Blazor WebAssembly (.NET 8)
    Shared Layer: Class Library for Shared DTOs and Data Models

Features Implemented

    Full-Stack C# Integration: End-to-end type safety using shared models between Web API and Blazor WASM.
    CORS & Integration Fixes: Fully configured HTTP Client factory and CORS middleware.
    Structured JSON Format: Standardized ApiResponse<T> contract.
    Performance: Async/await calls, efficient state updates, and client-side rendering.

How to Run

    Start the API (terminal in InventoryHub.API): dotnet run
    Start the Blazor Client (terminal in InventoryHub.Client): dotnet run
